# Account profile and local shopping ownership design
Profile: authenticated own display-name only edit, strict body/version, server role/identity authoritative. Phone/email cannot change through this endpoint; future verification required. No account/role/password/phone accepted. Public profile excludes secrets; session display refreshed without new token. Account profile version is independent of authVersion/session revocation.
Storage: demo unchanged. Connected mode uses API-origin + buyer/account ID scoped local cart/wishlist; guests have separate keys. Auth-pending screen never reads prior account data. Switching identity remounts local store before rendering new contents. Guest import is explicit, not automatic; keep separate leaves guest data intact. Import merges exact product/variant IDs, keeps existing account quantity for duplicate lines (does not sum), caps100 lines,999 quantity, wishlist1000, removes acceptedPrice on imported lines for server review. No claim of stock/price guarantee or server/device sync. Legacy unscoped storage is offered only via explicit import with ownership warning, never auto-assigned. Uncertain ordering attempts remain user-scoped and are not imported or deleted.

Implemented profile endpoints GET/PATCH /auth/profile with per-account rate limit and independent profileVersion. Contact fields display read-only, no role/identity target accepted. Frontend AccountProfile saves through service and refreshes /auth/me session name without token replacement; same-token name-change storage events update other tabs instead of signing out. Stale/failed saves preserve draft and ask for reload. Profile editing is name-only; phone/email changes remain explicitly unavailable pending verification flow.
AccountCartProvider remounts per ready identity/API-origin, uses isolated pending/guest/user keys; same-key storage events refresh local state. Explicit guest/legacy import banners are shown only for buyers and after scoped cart hydration. Duplicate lines preserve account qty, imported accepted price removed, capacity leftovers stay at source, cleanup after verified target writes. Orders/recovery storage never imported. Local storage is browser preferences, not encrypted data isolation or multi-device sync; same-account concurrent tab editing is last-write-wins. No backend cart/wishlist synchronization claimed.
