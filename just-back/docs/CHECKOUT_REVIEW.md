# Checkout review before orders

Decision: extend read-only checks with authenticated `POST /checkout/review`, without order creation or reservation. Strict request `{areaId,addressId,addressVersion,items:[{productId,variantId?,qty}],fulfilments:[{shopId,method}]}`; duplicate lines/shops, client money/ownership fields and unknown methods are invalid. Address version is compared with the server-owned address; changes require a fresh selection. Shop IDs are resolved from actual listings; selections for unrelated shops are rejected. Missing method selections are structured issues.

Reuse existing cart pricing/stock/minimum rules and address-coverage rules rather than implementing alternate pricing logic. Each selected method must exist and pass configured checks. Platform delivery remains unverified. Missing seller fee stays unknown. Return current item subtotal, selected listed fees and per-line/per-shop/general issues. Grand total remains null and `checkoutAvailable:false,reserved:false` regardless of eligibility: tax/discount policy, final delivery pricing, transactional reservations, idempotent order creation and payment lifecycle are not implemented.

This is a best-effort multi-read review, not an atomic quote or order token. The same timestamp is used for operating hours in both checks, but concurrent catalogue/address changes remain possible. Future checkout must atomically revalidate and reserve; these results must never be accepted as authoritative client input. No database writes, customer notifications, payments or fake orders occur.

## Integration and verification — 2026-10-29

The live bag now offers one method radio group per shop; unavailable and unverified methods cannot be selected. Address changes clear selections. Complete eligible selections trigger the combined review; query identity includes authenticated account, area, address/version, current line IDs/quantities and method choices. Changes hide/recompute obsolete results. The review displays current item subtotal, selected listed fees and all returned line/shop/method/general issues, without a payable total or submission action. Demo checkout remains unchanged.
