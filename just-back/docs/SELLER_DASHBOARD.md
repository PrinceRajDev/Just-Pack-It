# Seller daily dashboard design

GET /seller/dashboard is authenticated seller-only and derives its shop from the session. Strict no query overrides; private/no-store. Aggregate counters avoid downloading all order/product pages. Today follows saved shop timezone and server time; count is shop-wise orders created today, including later cancellation, excluding test orders and unpaid online orders. No sales/payout/earnings claim. Pending-payment placed orders are counted separately and never urgent processing actions. Pipeline counters cover all dates and exclude test/unpaid online orders. Urgent list is oldest five placed shop suborders, using existing safe seller DTO and versioned controls. Low-stock active listing/options threshold5; variants evaluated individually, inactive variants omitted, base stock ignored for variant products, ten examples with full total. Read model is not a transactional snapshot across collections and reserves nothing. Queries capped at5 seconds; large production workload/index benchmarking remains required. Existing setup remains available for pending shops; shop settings unchanged.
