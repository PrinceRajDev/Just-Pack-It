# Seller photo and account phone verification

Shop photo is optional at signup. Select/preview before account creation; upload only after the server creates the seller session and shop. Never expose anonymous image uploads. Upload failure must not trigger another account creation: tell the seller their account exists and offer retry in shop setup. The server attaches only to the authenticated seller's shop, checks optimistic version and returns pending approval after photo changes. Reuse current decoded-image validation/storage pipeline, with separate shop-image keys and uncertain-commit reference checks. Keep previously attached images until deliberate retention cleanup.

The user selected email OTP via Brevo HTTPS instead of paid SMS. New buyer/seller registration requires a server-verified, expiring, single-use email proof, with resend and guessing limits; see EMAIL_OTP.md. Push messaging credentials do not enable SMS authentication. Phone numbers remain unverified; existing accounts are not automatically marked email-verified. Seller shop approval remains separate from mailbox verification. Real email delivery awaits Brevo API key and verified sender configuration.
